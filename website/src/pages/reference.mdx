# React hooks

## useObservable()

A React hook that returns the current/latest value from an observable

**Signature**

```ts
function useObservable<T>(observable$: Observable<T>): T | null
function useObservable<T>(observable$: Observable<T>, options: UseObservableOptions<T>): T

interface UseObservableOptions<T> {
  disabled?: boolean
  initialValue?: T
}
```
