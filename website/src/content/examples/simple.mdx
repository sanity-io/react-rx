# Read your first observable

Start with a value that arrives once, then a value that changes over time. In both cases,
[`useObservable`](/reference#useobservable) reads the stream and handles the component's
subscription.

## Hello World

The component starts with `…`. Once it commits, `of('World')` emits and the greeting updates.
Try changing `World` in the editor. The explicit initial value is required even though `of` emits
synchronously when subscribed.

<HelloWorld />

## Counter

Watch the counter for a few seconds, then change the timer's second argument from `1000` to `500`.
It controls the interval in milliseconds. The observable lives outside the component so
rerendering does not create a new timer.

<Simple />

The hook supplies a value to render; RxJS decides when that value changes. You do not need an
effect or a separate state setter to copy each emission into React.
