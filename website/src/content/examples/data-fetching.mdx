# Suspense data fetching

[`useObservablePromise`](/reference#useobservablepromise) returns a promise for React's `use()`.

- The Suspense fallback shows until the first emission.
- Later stream updates render in place. They never re-trigger the fallback.

Try it: switch profiles (new observable, so it re-suspends) and watch the clock keep ticking without ever flashing a fallback.
