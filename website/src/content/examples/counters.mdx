# Compose timer streams

These examples keep timing and value transformations in RxJS. React reads the result with
[`useObservable`](/reference#useobservable).

## Configurable interval

Move the slider to change the interval. Each change creates a new timer, so the count restarts
after its initial 500-millisecond delay. `useMemo` recreates the observable only when the interval
changes; the slider itself uses ordinary React state.

<ReactiveState />

## Delayed tick

Watch the three displays together. One shows the main tick, one follows it after 300 milliseconds,
and one counts smaller ticks between the main ticks.

<DelayedTick />

`switchMap` replaces the inner timer whenever a main tick arrives. In the subtick display,
`sampleTime(20)` limits how often the stream emits a value for React to read.

## Fizz Buzz

Watch the output at multiples of three, five, and fifteen. The stream maps each timer value to a
label, then to an element, and stops after 100 emissions.

<FizzBuzz />

These are separate choices: RxJS controls timing and transformations, while the hook controls
how their output reaches the component.
