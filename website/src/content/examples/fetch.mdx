# Fetch requests

A minimal fetch-on-click: URL selections push into a `Subject`, `switchMap` runs the fetch (cancelling any in-flight one), and `distinctUntilChanged` skips repeat clicks on the same URL.

For production-shaped fetching, see [offline-resilient fetch](/examples/resilient-fetch) (retry, backoff, pause/resume) and [Suspense data fetching](/examples/data-fetching) (loading UI as a Suspense fallback).
